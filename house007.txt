[TYPOGRAPHY SYSTEM]

Use only the fonts explicitly defined by the HOUSE 007 design system.

Do NOT:
- Substitute a font automatically.
- Use browser defaults.
- Use Inter, Arial, Helvetica, Roboto, system-ui or another common default unless explicitly specified.
- Change font family per component without an explicit rule.
- Invent font sizes, weights, line heights or letter spacing when they are not defined.

Font family, font size, font weight, line height and letter spacing must be treated as controlled design-system values.

[GLOBAL DESIGN RESTRICTIONS — STRICT]

Claude must NOT invent, assume, or automatically add any visual styling that is not explicitly specified in this document.

If a visual property is not defined, do NOT create a design decision on your own.

STRICTLY PROHIBITED UNLESS EXPLICITLY SPECIFIED:

- Box Shadow / Drop Shadow
- Border Radius / Rounded Corners
- Border / Outline
- Divider Lines
- Default component borders
- Default browser styling
- Framework / component-library default styling
- Unspecified fonts or typefaces
- Unspecified font weights
- Unspecified gradients
- Unspecified glow effects
- Unspecified blur effects
- Unspecified glass effects
- Unspecified background decorations
- Unspecified icons
- Unspecified illustrations
- Unspecified hover effects
- Unspecified animations
- Unspecified transitions
- Unspecified scaling effects
- Unspecified color changes
- Unspecified decorative elements

IMPORTANT:
Do not add rounded cards simply because they are common in modern UI design.
Do not add shadows to create depth unless a shadow value is explicitly defined.
Do not add borders or outlines to visually separate elements unless explicitly defined.
Do not automatically use a common web font or framework default font.
Do not replace typography with icons.
Do not add decorative icons to buttons or navigation.

DEFAULT BEHAVIOR:

If a property is not specified:
1. Do not invent it.
2. Do not apply a trendy or modern UI pattern automatically.
3. Follow the established HOUSE 007 visual language.
4. Keep the element visually neutral until a specific value is provided.

IMPLEMENTATION RULE:

Do not use default browser or framework/component-library styling when it conflicts with this specification.

Every visual decision must come from one of:
- Explicit project specification
- Defined design system
- Existing supplied asset
- Explicit instruction given later by the project owner

If there is a conflict between a framework default and this specification, this specification always takes priority.
